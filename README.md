# Notepalooza AI
A playful landing experience for the Notepalooza brand. The page now includes a working in-browser "AI" sandbox so students can drop in raw notes and convert them into study-ready assets without leaving the site.

## Features
- Desktop-style GUI workspace that combines input, plan controls, mode picker, and output monitoring
- Capture shortcuts and text uploader that keep everything local to the browser
- Smart transformations: summaries, flashcards, quizzes, study guides, revision timetables, mind maps, and AI tutor scripts
- Subscription simulation with a Free plan (3 conversions/day) and Plus plan (unlimited + premium modes)
- Copy/download buttons so you can quickly export any generated result

## Getting started
Open `index.html` in any modern browser. All assets are local and no build tools are required.
